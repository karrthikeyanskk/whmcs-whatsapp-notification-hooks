# WHMCS WhatsApp Notifications - ShoHost WHMCS WhatsApp Module

Send WhatsApp messages to your WHMCS clients automatically: new invoices, payment confirmations, ticket replies, OTP and more.

This repository is the public info page for the **[ShoHost WHMCS WhatsApp Module](https://shohost.com/whmcs-whatsapp-module)**, an in-house WHMCS addon built by ShoHost.

## What it does

- Automatic WhatsApp alerts for invoices, payments, orders and support tickets
- OTP and verification messages
- Bulk campaigns to your client list
- Delivery tracking
- Works with the latest WHMCS versions
